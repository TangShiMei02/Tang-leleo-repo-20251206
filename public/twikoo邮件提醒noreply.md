# 博客评论邮件提醒配置备忘 (Twikoo SMTP)

本文档用于记录个人博客 `blog.224418.xyz` 评论邮件提醒的实现原理与配置参数，防止日后遗忘或配置丢失。

## 📌 1. 整体工作原理
目前的邮件提醒流程如下：
1. 访客在博客的 Twikoo 评论区留言。
2. 博客前端的 Twikoo 组件将数据发送给后端。
3. 后端（通过 SMTP 协议）连接到邮件发送服务商（目前是 Resend，备用是 163 邮箱）。
4. 服务商将通知邮件发送到指定收件箱（博主或评论者）。

## ⚠️ 4. 核心避坑指南（血泪教训）

1. **绝对隔离原则**：
   - `me@224418.xyz` (主账号) 只能用于**个人博客**的评论提醒。
   - **严禁**将任何“临时邮箱 (Temp Mail)”项目（如 `mail.224418.xyz`）接入此账号或使用该域名发信！一旦被举报或风控，主账号必死。
   - 之前被封的两个账号（163 和 QQ 注册的）就是因为绑定了 `tsmail.cc.cd` 做临时邮箱被永久封禁。

2. **Resend 风控预警**：
   - Resend 对免费白嫖账号和垃圾邮件极度敏感。
   - 如果使用 Resend 发信，**不要短时间内测试群发**，容易触发风控导致封号。

3. **Twikoo 配置细节**：
   - Twikoo 后台配置时，`SENDER_EMAIL`（发件人邮箱）和 `SMTP_USER`（用户名）必须**完全一致**。
   - 修改 SMTP 配置后，**有 10 分钟左右的缓存**。测试没收到邮件别着急，等 10 分钟后再试。
   - 如果用 Vercel 部署，记得在 Vercel 项目设置中关闭 `Vercel Authentication`，否则无法触发邮件。

4. **收不到邮件怎么办？**
   - 先去垃圾箱（特别是 QQ 邮箱，经常把 163 或个人域名发来的通知判定为垃圾邮件）。
   - 把发件人加入白名单。
   - 检查 API Key 或授权码是否过期/填错。
